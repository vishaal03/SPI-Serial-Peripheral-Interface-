
# SPI (Serial Peripheral Interface) — One Master and Six Slaves

## Project Overview
This project implements a **Serial Peripheral Interface (SPI)** communication system in **SystemVerilog**, featuring **one SPI Master** and **six SPI Slaves**.  
It demonstrates full-duplex serial communication, where the master controls the data flow and timing, while each slave device communicates through its own Chip Select (CS) line.

The setup is ideal for understanding multi-slave SPI bus behavior, timing, and protocol-level synchronization in digital design or FPGA environments.

---

## Features
- One **Master** controlling six **independent Slaves**  
- Each slave selected via a **dedicated Chip Select (CS₀–CS₅)** line  
- Supports **8-bit data transfer** per frame (configurable)  
- Compatible with **SPI Mode 0** (CPOL = 0, CPHA = 0)  
- Simple, synthesizable SystemVerilog code for FPGA or ASIC projects  
- Includes a **Testbench** that verifies communication between the master and all slaves sequentially  


---

##  Working Principle
1. **Master** drives the **SPI clock (SCLK)** and **Chip Select (CS)** lines.  
2. When a CS line goes **LOW**, the corresponding **Slave** becomes active.  
3. **MOSI** line carries data from the master to the selected slave.  
4. **MISO** line carries data back from that slave to the master.  
5. All other slaves ignore the transfer when their CS is **HIGH**.  
6. After transmission, CS returns **HIGH**, deselecting the slave.  

---

##  Testbench Description
The provided testbench performs the following:
- Initializes the SPI bus.  
- Sends unique data from the master to each of the six slaves.  
- Each slave returns a predefined response (for example, its ID number).  
- Master verifies that responses match the expected data.  
- Displays transaction details using `$display` for easy waveform debugging.

---

##  SPI Signal Summary

| Signal | Direction | Description |
|:--------|:-----------|:-------------|
| **SCLK** | Master → Slaves | Serial Clock generated by the master |
| **MOSI** | Master → Slaves | Master Out, Slave In – carries data from the master to slaves |
| **MISO** | Slaves → Master | Master In, Slave Out – carries data from the selected slave to the master |
| **CS[0:5]** | Master → Individual Slaves | Active-low chip select lines for each slave |
